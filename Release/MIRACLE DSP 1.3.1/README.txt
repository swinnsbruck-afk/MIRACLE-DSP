QUICK START

  1. Double-click "MIRACLE DSP Installer.pkg".
     If macOS reports an unidentified developer:
     right-click the file -> Open -> Open.
  2. Confirm the installation with your Mac password.
  3. Restart your DAW (in Logic: Instrument -> AU Instruments -> ESS76).
  4. In the plugin, press Upper or Lower under LOAD, choose a sample folder or
     WAV file and step through the sounds with Snd UP/DOWN. Oct UP/DOWN
     transposes in octaves. The EDIT PANEL key opens all controls.


SYSTEM

  macOS 11 or later, Apple Silicon or Intel.
  Formats: Audio Unit, VST3, standalone.
